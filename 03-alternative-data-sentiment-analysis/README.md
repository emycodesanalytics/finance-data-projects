# 03. Alternative Data & Sentiment Analysis

**Status: In Progress**

This project explores the use of alternative data sources (Google Trends, social media sentiment, etc.) and their relationship with stock price movements in the Nigerian market.

## Planned Scope
- Google Trends data collection and analysis
- Sentiment analysis using TF-IDF and other techniques
- Correlation between sentiment and equity performance
