# 02. Financial Data Cleaning Pipeline

**Status: In Progress**

This project aims to build a reusable, modular pipeline for cleaning and preprocessing messy financial time series data, with special focus on Nigerian market data from sources like NGX Pulse and Investing.com.

## Planned Scope
- Handling missing values, outliers, and irregular timestamps
- Price and volume data standardization
- Feature engineering (log returns, rolling statistics, etc.)
- Data validation and quality reporting
